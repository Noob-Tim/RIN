# RIN v1.2 角色复现包

本版完成 **40 张独立参考图**：穿搭、场景、发型、表情、复合组合各 8 张；另含 **3 张独立重复复现测试图**。保留标准母图、五官拆解检查图、三视角辅助及此前 3 项测试。

先打开 `RIN_参考图册.html`，按分类或编号找图。解压后可离线搜索、复制复用提示词，并打开包内全尺寸 PNG。

## 每次还原 RIN

1. 提供 `RIN_母参考图.png` 和 `RIN_角色固定提示词.md`。母图必须实际传给生成模型。
2. 指定当次发型、穿搭、表情、场景与镜头；必要时附上所选编号对应的图。
3. 明确母图负责五官身份，辅助图只借用指定因素；发色、发型和饰物可以改变。
4. 出图后核对脸型、眼型、眉眼关系、鼻嘴比例、绯红虹膜及自身左眼下单颗痣。

> 按 RIN v1.2 母图和固定提示词还原 RIN。采用 H05 的蓝黑露额长直发、O04 的通勤西装，在 S03 车站场景中，参考 E07 的认真神情，膝上构图。母图负责五官身份，其他图只负责指定造型、环境或情绪。

更多直接可用的写法见 `RIN_调用模板.md`。新会话无法读取项目时，重新附上母图和固定提示词。

## 文件用途

| 文件／目录 | 用途 |
| --- | --- |
| `RIN_母参考图.png` | 主要五官身份与画风依据 |
| `RIN_角色固定提示词.md` | 固定五官、可变造型、生成与验收规则 |
| `RIN_调用模板.md` | 基础还原、编号组合、局部修改与新会话写法 |
| `outfits/` | O01–O08，纯色棚拍背景的全身穿搭 |
| `scenes/` | S01–S08，空间层次与道具较丰富的场景 |
| `hairstyles/` | H01–H08，完整发顶；含完全露额造型 |
| `expressions/` | E01–E08，微笑、大笑、惊讶、生气、含泪、害羞、坚定、困倦 |
| `combinations/` | C01–C08，发型、穿搭、表情与环境同时变化 |
| `repeat_tests/` | R01–R03，同一组合独立生成三次，保留未经修正的输出 |
| `gallery/` | 5 张分类总览、5 张五官对照、重复测试总览与五官对照；均为原图排版或裁切 |
| `RIN_扩充索引.md` | 40 张参考的编号、原图链接与使用注意 |
| `RIN_参考图册.html` | 内嵌缩略图，可筛选、搜索和复制提示词 |
| `RIN_扩充提示词.json` | 40 项提示词、输入图职责、实际操作记录及重复测试 |
| `RIN_生成提示词记录.md` | 可阅读的实际生成与修改提示词档案 |
| `RIN_扩充验收记录.md` | 五官人工检查、实际造型偏差与验证边界 |
| `RIN_重复复现检查.md` | C01 与 R01–R03 四个输出的同条件检查 |
| `references/` | 五官检查与三视角辅助 |
| `tests/` | 原有日光、夜景与换发色／发型测试 |
| `originals/` | 原材料备份，非当前母图权威 |
| `manifest.json` | 文件尺寸、SHA-256 与完整性清单 |

本批身体比例供全身示例统一使用，尚未定稿精确身高与人体数据。复现依靠视觉参考、明确提示词和输出检查；四个重复样本不能保证所有未来生成都完全一致，也没有训练专属角色模型。
